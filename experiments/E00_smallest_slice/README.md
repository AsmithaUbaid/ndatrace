# E00 — Smallest working slice

This artifact documents the smallest working slice used to establish the end-to-end path. It is
not a new evaluation experiment and does not change any reported metrics.

## What it demonstrates

One NDA + one requirement -> one model call/inference path -> one structured classification -> one
evidence result:

```
NDA text + requirement text
  -> pipeline/frozen_rag.py (FrozenRagRetriever: clause-aware chunk -> BM25 -> cross-encoder rerank -> top-5)
  -> pipeline/final_review.py's review_final() (production runtime function, not a duplicate)
       -> model call (GPT-5-mini + frozen P0 prompt)
       -> evaluation/structured_output.py parser
       -> pipeline/evidence_validator.py (verbatim-quote check)
  -> one label (Entailment / Contradiction / NotMentioned) + one evidence quote
```

**Success is defined as:** a requirement is successfully processed when the system returns a valid
label and source-grounded evidence that a reviewer can inspect.

## Why this exists

The submission's watch-outs require a smallest working slice to be documented alongside the full
experiment ladder (E01-E22). This directory fills that gap by reusing the current, frozen
production components (`pipeline/final_review.py`, `pipeline/frozen_rag.py`) rather than a
separate or historical implementation.

## Files

- `run_smallest_slice.py` — runs the slice. `--dry-run` (default) uses a stub model gateway
  (fixed, deterministic response, zero network calls, zero cost) so this script never silently
  makes a paid API call. `--live` makes one real hosted call via the production `ModelGateway`
  (requires `OPENROUTER_API_KEY`).
- `example_input.json` — the one deterministic fixture: a short synthetic NDA excerpt and one
  confidentiality requirement.
- `example_output.json` — the result of the last `run_smallest_slice.py` run (regenerated by the
  script each time it runs; not hand-written).

## Running it

```bash
python3 experiments/E00_smallest_slice/run_smallest_slice.py          # dry-run, $0, no network
python3 experiments/E00_smallest_slice/run_smallest_slice.py --live   # one real hosted call
```
